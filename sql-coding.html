SQL Practice Lab:

Step 1: Database & Table Creation

Concept:

  • Database → container for tables
  • Table → collection of structured data in rows and columns
  • Primary Key → unique identifier for a record

Challenge 1: Create a Database

Goal: Create a database for your practice

Task:

  • Name the database anything you like (e.g., CompanyDB)
  • Use CREATE DATABASE

Hints:

  • Syntax: CREATE DATABASE database_name;
  • Predict: What happens if the database already exists?

Expected Behavior:

{ Query OK, 0 rows affected (0.07 sec) } - Database is created and can be selected for use

Challenge 2: Create Tables

Goal: Create Employees and Salaries tables

Task:

  • Employees → EmpID (number), EmpName (text), City (text)
  • Salaries → SalaryID (number), EmpID (number), Amount (number)

Hints:

  • Use CREATE TABLE table_name (column1 datatype, ...);
  • Think about primary keys for uniqueness

Expected Outcome:

{ Query OK, 0 rows affected (0.07 sec) } - Tables created successfully

Step 5: JOINS

Concept:

  • Combine data from multiple tables using JOINs
  • INNER JOIN → only matching rows
  • LEFT JOIN → all rows from left table
  • RIGHT JOIN → all rows from right table

Challenge 9: INNER JOIN

Task:

  • Show employee names with their salary amounts

Hints:

  • Join on EmpID
  • Syntax:
SELECT Employees.EmpName, Salaries.Amount
FROM Employees
INNER JOIN Salaries
ON Employees.EmpID = Salaries.EmpID;

Expected Output:

EmpName | Amount
----------------
Priya   | 40000

Challenge 11: RIGHT JOIN

Task:

Mentor Notes

  • Always predict output before running queries
  • Use WHERE for filtering and JOINs to combine tables
  • GROUP BY + HAVING → analyze aggregates
  • ORDER BY → sort results
  • Practice adding, updating, deleting data to see effects
  • Keep experimenting with edge cases (empty tables, duplicates, NULL values)
