Python Practice Lab

Step 0: Make Sure Python is Ready

Before coding, check:

  • Is Python installed?
python --version

or

python3 --version
  • Can you run a Python script?
python hello.py

Tip: Use any editor: VS Code, PyCharm, or even online editors like replit.com.

Step 1: Your First Python Code

Python is simpler than Java:

  • No semicolons at the end
  • No curly braces {}
  • Indentation is important (usually 4 spaces)

Challenge 1: Hello, World!

  • Print Hello, World! to the console

Hints:

  • Use print() function
  • Don’t use semicolons
  • Syntax: print("text")

Expected Output:

Hello, World!

Pitfalls:

  • Forgetting parentheses → SyntaxError
  • Incorrect indentation → IndentationError

Step 2: Variables and Data Types

Python is dynamically typed:

  • int → whole numbers
  • float → decimals
  • str → text
  • bool → True/False

Challenge 2: Create Your Personal Info

  • Create variables: name, age, height
  • Print: "Hi, I am <name>, I am <age> years old and <height> ft tall"

Hint:

  • Use f-strings for clean formatting:
print(f"Hi, I am {name}, I am {age} years old and {height} ft tall")

Expected Output Example:

Hi, I am Sunny, I am 21 years old and 5.8 ft tall

Edge Cases:

  • age = "21" (string instead of int) → arithmetic operations may fail
  • height = 5.8 → floating-point number works fine

Challenge 3: Update & Print Variables

  • Change your age and height variables
  • Print updated info in one statement

Expected Output Example:

Hi, I am Sunny, I am 22 years old and 5.9 ft tall

Hints:

  • Just reassign variables: age = 22
  • f-strings automatically reflect updated values

Challenge 4: Math with Variables

Python Mini Challenge: Student Score Analysis

Goal: Write a program that:

  1. Stores a student’s name, age, and marks for 3 subjects
  2. Calculates total marks, average marks, and percentage
  3. Prints grade based on percentage:
    • 90+ → "A"
    • 80–89 → "B"
    • 70–79 → "C"
    • else → "Fail"
  4. Checks if the student is adult (age ≥ 18)
  5. Prints subject-wise pass/fail (passing ≥ 35 marks)

Hints:

  1. Variables & Data Types:
    • Name → string
    • Age → integer
    • Marks → integers (or a list for multiple subjects)
  2. Operators & Expressions:
    • Total = sum of marks
    • Average = total / 3
    • Percentage = (total / 300) * 100
  3. If-Else & Elif:
    • Use if-else for adult check
    • Use elif ladder for grade calculation
    • Use if-else inside a loop to check each subject pass/fail
  4. Loops:
    • Use a for loop to iterate over subjects for pass/fail

Concept:

  • A class is a blueprint for objects.
  • An object is an instance of a class.
  • Attributes store data; methods define behavior.

Step 2: Inheritance & Polymorphism

Concepts:

  • Inheritance: Child class inherits attributes/methods from parent class
  • Polymorphism: Same method behaves differently in parent/child
  • Single inheritance → supported
  • Multiple inheritance → Python supports, but Java-style multiple class inheritance is not allowed

Challenge 3: Single Inheritance

Goal: Create Person (parent) and Student (child)

  • Child class: Student → roll_no, override display()
  • Create object of Student and call display()

Expected Output:

Student: Sunny, Roll No: 101

Hints:

  • Use super().__init__(name) to initialize parent class attributes
  • Override method in child for polymorphism

Challenge 4: Polymorphism with Functions

Edge Cases:

  • Forget overriding → parent method executes
  • Multiple inheritance conflicts → Python uses MRO (Method Resolution Order)

Exception Handling

Step 1: Introduction to Exceptions

Concept:

  • An exception occurs when Python encounters an error during execution.
  • Try-Except blocks handle exceptions without stopping the program.
  • Common exceptions: ZeroDivisionError, ValueError, TypeError, IndexError, KeyError.

Syntax:

try:
    # code that might raise exception
except ExceptionType:
    # handle exception

Challenge 1: ZeroDivisionError

Goal: Handle division by zero

Hints:

Expected Output:

Cannot divide by zero

Edge Cases:

  • Change b = 2 → should print 5.0
